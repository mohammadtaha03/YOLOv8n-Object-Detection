# YOLOv8-Object-Detection
Detecting objects in images using the YOLOv8 nano model and Python.

## Built With
- Python
- [Ultralytics YOLOv8](https://github.com/ultralytics/ultralytics)

## How to Run
```bash
git clone https://github.com/mohammadtaha03/YOLOv8n-Object-Detection.git
cd YOLOv8n-Object-Detection
pip install -r requirements.txt
python main.py
```

The YOLOv8n model weights are downloaded automatically on first run.
